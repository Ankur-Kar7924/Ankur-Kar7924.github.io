Privacy Policy: gmail-digest

Last updated: October 11, 2026

Who uses this app

gmail-digest is a personal tool used only by its developer, Ankur Kar, on his own Gmail account. It has no other users.

What data it accesses

The app requests read-only access to Gmail (the gmail.readonly scope). It reads the sender, subject and content of recent emails in the owner's inbox. It cannot send, delete or modify email.

How the data is used

Email content is processed by a language model running locally on the owner's own computer to produce a short daily summary. The summary is sent to the owner's phone as a push notification. Email content is not sold, shared with advertisers, or used to train any model.

Storage

The app stores only an OAuth access token on the owner's computer so it can run on a schedule. Email content is not stored after the summary is generated.

Google API Services User Data Policy

gmail-digest's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
